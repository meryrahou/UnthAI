# 🤜🤛 Team Annotation Toolkit

## 🚀 1. Launch the Suite
Execute this one-liner from the project root:
```bash
cd 03_annotation/team_toolkit && ../../venv/bin/python launcher.py
```
*(This pulls unlabeled rows, runs the AI, filters for active suggestions, and opens the tool.)*

## ⚡️ 2. High-Speed Shortcuts
- **Press `S`**: Accept AI Suggestion ➡️ Save ➡️ Next.
- **Press `D`**: Save current selection (even "None") ➡️ Next.

## 2. Annotate at Light-Speed
- Open **[http://localhost:8000](http://localhost:8000)**
- Look for the **Rainbow Border** 🌈 (AI's prediction).
- **Press `S`** to accept the suggestion, save, and go to next! ⚡️
- **Click anywhere** in a label's box to select it if the AI is wrong.

## 3. Finish & Sync
When done:
1. Close browser tab.
2. Press **`CTRL+C`** in your terminal.
3. Your work will **automatically merge** back to the master file.
